# 📋 Menu Responsivo - HTML + CSS

Este é um projeto de **menu de navegação responsivo**, desenvolvido com **HTML e CSS puro**, com base em um design elaborado no **Figma**. O objetivo foi criar um menu funcional, moderno e adaptável para **dispositivos desktop e mobile**, aplicando boas práticas de layout responsivo e usabilidade.

## 🎨 Design

O layout do menu foi desenhado no [Figma](https://www.figma.com), onde defini a estrutura visual, cores, espaçamentos e comportamento em diferentes resoluções de tela. O design prioriza simplicidade, legibilidade e navegação intuitiva.

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- Figma (para prototipação)

## 📱 Funcionalidades

- Menu horizontal para telas maiores (desktop)
- Menu colapsável ou empilhado para dispositivos móveis (mobile)
- Estilo visual moderno e responsivo
- Transições suaves (se aplicável)
- Acessibilidade básica com uso de elementos semânticos

## 💡 Aprendizados

Durante o desenvolvimento, aprofundei meus conhecimentos em:
- **Media queries**
- **Flexbox e Grid layout**
- Responsividade sem o uso de JavaScript
- Conversão de design Figma para HTML/CSS
